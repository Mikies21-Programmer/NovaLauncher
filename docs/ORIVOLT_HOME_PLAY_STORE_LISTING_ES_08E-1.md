### Descripción completa

Orivolt Home es un launcher de Android para organizar y personalizar tu pantalla de inicio.

Crea y ajusta pantallas de inicio con accesos directos. Explora tus aplicaciones en un cajón con categorías, índice alfabético y búsqueda. Añade widgets de las aplicaciones que elijas y consulta un indicador de RAM del sistema.

Personaliza la interfaz con opciones de estilo, idioma español o inglés y fondos o iconos que selecciones desde tu dispositivo. Si no eliges un fondo, Orivolt Home muestra un degradado estático integrado.

Apps ocultas permite retirar aplicaciones seleccionadas del cajón, las categorías y la búsqueda. Puedes proteger el acceso con las opciones disponibles en tu dispositivo o con una credencial configurada para esta función.

De forma opcional, puedes conceder acceso a notificaciones para mostrar un contador de mensajes pendientes. También puedes activar el Servicio de Accesibilidad para bloquear la pantalla con doble toque y abrir el panel de notificaciones con un gesto o desde el contador. Antes de abrir los Ajustes de Android, Orivolt Home explica esa finalidad y te permite aceptar o cancelar. El servicio no recupera contenido de ventanas ni procesa eventos de accesibilidad.

Algunas funciones dependen de componentes que tú eliges o habilitas, como widgets de otras aplicaciones, el selector de Android, el acceso a notificaciones y la accesibilidad. Consulta la política de privacidad: https://mikies21-programmer.github.io/OrivoltHome-Privacy/
