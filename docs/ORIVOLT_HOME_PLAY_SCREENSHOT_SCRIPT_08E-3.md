# Orivolt Home — guion de capturas reales para Play (08E-3)

## Preparación común

1. Usar la AAB/APK Release candidata `com.daybreak.animelauncher` versión `1.6.1` (versionCode 9) en un perfil Android de prueba limpio, sin cuenta personal.
2. Establecer Orivolt Home como launcher y dejar el fondo predeterminado: el degradado estático dibujado por la aplicación. No seleccionar fondos WebP, fondos históricos ni vídeos.
3. Configurar idioma español para las capturas ES y repetir en inglés para las capturas EN si contienen texto de la interfaz. Mantener fecha, hora, batería y conectividad sin información personal cuando el sistema las muestre.
4. Usar sólo apps de prueba sin cuentas, nombres privados, conversaciones ni notificaciones sensibles. Desactivar o limpiar notificaciones. No usar nombres, iconos o contenido que no se puedan mostrar públicamente.
5. Capturar la pantalla real del dispositivo, sin marco de teléfono, composición externa ni superposiciones que parezcan parte de la app. Exportar PNG/JPEG de 24 bits, sin alfa, idealmente 1080 × 1920 vertical.

## Secuencia propuesta

| Orden | Pantalla real a capturar | Preparación y encuadre | Comprobación antes de conservarla |
| ---: | --- | --- | --- |
| 1 | Inicio (Home) | Mostrar una pantalla inicial ordenada con accesos de prueba y el degradado estático. | Se ve Orivolt Home; no hay fondo bloqueado, notificaciones, apps privadas ni identidad Nova/Anime. |
| 2 | Cajón de aplicaciones | Abrir el cajón; mostrar una categoría y el índice alfabético o la búsqueda vacía. | La lista sólo contiene apps permitidas para demostración; no usar términos de búsqueda personales. |
| 3 | Configuración / personalización | Abrir Ajustes y mostrar opciones de estilo, idioma o RAM visibles en la UI. | No mostrar datos de cuenta, URI de archivos ni recursos bloqueados. |
| 4 | Widgets del sistema | Mostrar el flujo real de añadir widget o un widget de prueba ya añadido, únicamente si un proveedor de prueba está disponible. | El widget no revela calendario, correo, clima asociado a ubicación, cuenta o datos de terceros. Si no hay proveedor seguro, omitir esta captura. |
| 5 | Apps ocultas (opcional) | Mostrar sólo la entrada o configuración inicial, sin seleccionar aplicaciones reales ni revelar una credencial. | No capturar contenido protegido, patrón, PIN, biometría ni nombres sensibles; esta pantalla no sustituye las cuatro primeras. |
| 6 | Accesibilidad (opcional) | Mostrar la divulgación interna previa a “Aceptar y configurar”, no los Ajustes del sistema con datos ajenos. | Debe explicar una función real; no sugerir que la app es una herramienta de accesibilidad ni que recoge contenido de ventanas. |

## Criterio de selección y orden de carga

- Subir primero las capturas 1–4 si las cuatro pasan la revisión; representan Home, cajón, configuración y widgets de forma real.
- Si widgets no se pueden mostrar de forma segura, usar 1–3 y añadir una captura real de Apps ocultas en configuración inicial. No inventar un widget.
- Usar las capturas opcionales sólo si aportan una función visible y se pueden sanear sin alterar la experiencia.
- Verificar en la vista previa de Play Console que no se recorten elementos esenciales. Conservar los archivos originales y anotar dispositivo/API/versión/idioma para trazabilidad.
